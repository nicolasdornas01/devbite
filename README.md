# DevBite

Interface de um sistema de pedidos de lanchonete, feita só com HTML5 e CSS3.
Trabalho da faculdade.

## Telas

- **Cardápio** (`index.html`): produtos separados por categoria (lanches, bebidas e sobremesas), cada um com foto, descrição, preço e botão de adicionar.
- **Carrinho** (`checkout.html`): itens do pedido com quantidade e total, mais o formulário de entrega e forma de pagamento.
- **Admin** (`admin.html`): tabela com os pedidos do dia e formulário para cadastrar produto.

## Tecnologias

- HTML5 semântico
- CSS3 (Flexbox, Grid e media queries)
- Google Fonts (Lilita One e Nunito)

Sem JavaScript e sem framework por enquanto. Os campos e botões já têm `id`, `name` e `data-id` para receber JavaScript depois.

## Como abrir

Baixe ou clone o repositório e abra o arquivo `index.html` no navegador. As outras telas abrem pelo menu.
